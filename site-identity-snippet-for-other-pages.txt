ASAP-Bio — site identity tags for the OTHER pages
==================================================

The finished index.html (delivered separately) already has everything.
For the other pages (about.html, partners.html, themes.html, knowledge.html,
scholarships.html, news.html, contact.html, collaborators.html), paste the
block below inside each page's <head>, right after that page's
<meta name="description" ...> line.

Change ONLY the two "og:url" / canonical values to match each page's address,
and adjust og:title to that page if you like (or leave it as "ASAP-Bio").
The og:site_name MUST stay "ASAP-Bio" on every page — that is the value that
tells Google the site is called ASAP-Bio, not GitHub.

------------------------------------------------------------------
<link rel="canonical" href="https://asap-bio.github.io/PAGE.html">
<meta property="og:type" content="website">
<meta property="og:site_name" content="ASAP-Bio">
<meta property="og:title" content="ASAP-Bio">
<meta property="og:url" content="https://asap-bio.github.io/PAGE.html">
<meta property="og:image" content="https://asap-bio.github.io/assets/emblem.png">
------------------------------------------------------------------

You do NOT need to repeat the two <script type="application/ld+json"> blocks on
every page — they belong on the home page (index.html) and that is enough for
the site-name signal. Putting them only on index.html is cleanest.

After you publish:
1. Commit the updated files to your GitHub repo.
2. In Google Search Console (search.google.com/search-console), if the site is
   verified, use "URL Inspection" on https://asap-bio.github.io/ and click
   "Request indexing". This asks Google to re-crawl sooner.
3. Give it days to a few weeks. Google decides when to update the snippet; the
   tags make "ASAP-Bio" the strong, explicit signal, but the timing is Google's.
